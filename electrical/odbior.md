- [ ] Reset bez grzyba nie puszcza ruchu
- [ ] Start: sprzeglo, potem czujnik wejscia, rejestracja, wyjscie
- [ ] Licznik arkuszy +1

- [ ] Stop z arkuszem na czujniku daje JAM
- [ ] Reset przy zaslonietym czujniku nie kasuje JAM
- [ ] Otwarta pokrywa zrzuca bieg
- [ ] %QW1 zgadza sie ze stanem na panelu
- [ ] Start przy rolce ponizej 70 C nie wlacza sprzegla
- [ ] Po wejsciu w pasmo 70..95 C start podaje arkusz
- [ ] Powyzej 95 C jest FAULT, grzalka zgaszona, %QW7 = 2
